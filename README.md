# RLiOS

An experimental native iOS game core (C++20 + thin Swift shell + Metal) aiming to reproduce a
fixed-120 Hz, bit-exact deterministic vehicle-ball simulation and its presentation on iPhone.

This repository contains **only our own source code**. It contains no game files, extracted or
converted assets, or reference data of any kind, and it requires your own legally obtained copy
of the original game for any reference work. Current state: Milestone 1 "Skeleton" (the
simulation is a labelled placeholder, not real physics).

See `CLAUDE.md` for build and test commands.
